Control de grúa torre con ESP32 (4 bits + compuertas)

Azul = GIRO de la pluma (↔ horizontal) Naranja = IZAJE del gancho (↕ vertical) Rojo = INTERLOCK de seguridad
Modo: MODO 1 // BINARIO
Entrada: 0000 (DEC 0)
Salida 4 bits: 0000 (DEC 0)
Servo 1 · Giro: 0° // 500 µS
Servo 2 · Izaje: 0° // 500 µS
Pluma en G0 (0°), gancho abajo (Z0)
1. Botonera de 4 pulsadores PALABRA BINARIA 4B
MODO 1 (BINARIO): [B3 B2] = GIRO DE LA PLUMA (SERVO 1) Y [B1 B0] = IZAJE DEL GANCHO (SERVO 2).
B3 (2³) MORADO GIRO MSB
B2 (2²) AZUL GIRO LSB
B1 (2¹) VERDE IZAJE MSB
B0 (2⁰) AMARILLO IZAJE LSB
Salida (lo que recibe la grúa): PATRÓN: 0000 (DEC 0)
S3 = 0
S2 = 0
S1 = 0
S0 = 0
Cruceta: mueve la grúa paso a paso
Giro G0 · Izaje Z0 (teclado: flechas, Inicio = home)
2. La grúa (vista lateral y superior) SALIDA: 0000 (DEC 0)
3. Circuito de compuertas (Modo 2) 74HC04 / 08 / 32
Estás en Modo 1 (directo, sin interlock). Clic aquí para activar el Modo 2 (compuertas con interlock).
S3 = E3 S3 = 0
S2 = E2 S2 = 0
S1 = E1 S1 = 0
S0 = E0 + (E3 + E2) · E1' (interlock) S0 = 0

Cómo funciona el Modo 2:
• [E3 E2]: giro que pides, G0..G3 (0°, 45°, 90°, 135°). Pasa igual a [S3 S2].
• [E1 E0]: altura que pides, Z0..Z3 (Z0 = gancho abajo, Z3 = arriba).
• Interlock: si la pluma no está en G0 y pides Z0, el gancho sube a Z1 para que la carga no choque con el pedestal al girar. En G0 la altura pasa tal cual.
